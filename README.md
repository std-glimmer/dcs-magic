# DCS: Magic

Клиент-серверная система ситуационной осведомлённости (GCI / AWACS) для **DCS World**.

Скрипт экспорта внутри DCS World забирает данные о юнитах на карте и отправляет их по
UDP на сервер. Сервер авторизует операторов по коалициям, записывает поток данных в
«треки» и ретранслирует юниты по TCP каждому клиенту — только те, что доступны его
коалиции. Клиент отображает юниты на интерактивной карте (Qt Location / OSM),
позволяет смотреть детали и проигрывать сохранённые записи.

---

## Возможности

- **Приём телеметрии по UDP** от DCS World (мировые объекты: название, тип, коалиция,
  широта/долгота/высота, курс).
- **Авторизация по коалициям**: `Мастер игры`, `Красная`, `Синяя`, `Нейтральная` — у каждой
  свой пароль, хранящийся в SQLite (`settings.db`).
- **Фильтрация по коалиции**: клиент получает только юниты, доступные его коалиции
  (Мастер игры видит всё).
- **Многопоточный TCP-сервер**: каждое подключение обслуживается в отдельном потоке.
- **Запись и проигрывание треков**: весь входящий поток сохраняется в файл, затем его можно
  пошагово воспроизвести на клиенте через слайдер.
- **Клиент с картой**: карта OSM (QtLocation), иконки юнитов по типу и коалиции,
  ночной/дневной режим карты, всплывающие подписи с именем и высотой юнита.
- **Экспорт NMEA** (GPS-телеметрия) — вспомогательный Lua-скрипт для сторонних устройств.

## Архитектура

```
+-----------------+      UDP :6026       +-----------------------+
|   DCS World     | -------------------> |      dcs-magic-server |
| MagicExport.lua |   строка с юнитами   |   (UDPReceiver)       |
+-----------------+                      |          |            |
                                         |          v            |
                                         |   RecordsManager      |  <- запись трека
                                         |          |            |
                                         |          v            |
                                         |   ConnectionManager   |
                                         |   ClientThread (N)    |
                                         +----------+------------+
                                                    | TCP :9085
                                    авторизация + поток юнитов
                                                    |
                        +---------------------------+---------------------------+
                        v                           v                           v
              +------------------+        +------------------+        +------------------+
              | dcs-magic-client |        | dcs-magic-client |        | dcs-magic-client |
              |  (Красная)       |        |  (Синяя)         |        |  (Мастер игры)   |
              +------------------+        +------------------+        +------------------+
                        |
                        v
              UnitsManager -> MainWindow -> QML Map (BaseTrack)
```

Сервер и клиент используют общую библиотеку `lib/` (`UnitsManager`, `UnitObject`,
`RecordsManager`) — единый парсер сообщений и модель юнита.

## Протокол обмена

### 1. DCS → сервер (UDP, порт 6026)

Скрипт `MagicExport.lua` раз в `0.25 с` отправляет пакет, содержащий по одной строке
на каждый юнит; строки разделены `;`:

```
<time>,<UnitTitle>,<UnitName>,<Level1>,<Level2>,<Level3>,<Level4>,<CoalitionID>,<Lat>,<Long>,<Alt>,<Heading>;
```

| Поле           | Описание                                                                 |
| -------------- | ------------------------------------------------------------------------ |
| `time`         | Игровое время (LoGetModelTime)                                           |
| `UnitTitle`    | Как тип называется в игре                                                |
| `UnitName`     | Уникальное имя юнита (ID)                                                |
| `Level1..4`    | Иерархия типа юнита (Air/Ground/Navy → самолёт/вертолёт/корабль/ПВО → …)  |
| `CoalitionID`  | Коалиция DCS (1 — Red, 2 — Blue, 3 — Neutral)                            |
| `Lat/Long/Alt` | Координаты и высота                                                      |
| `Heading`      | Курс                                                                     |

### 2. Клиент ↔ сервер (TCP, порт 9085)

1. Клиент подключается → сервер отвечает строкой `connected`.
2. Клиент отправляет авторизацию:

   ```
   coalition:<r|b|g|n>;password:<пароль>;
   ```

   где `r` — Красная, `b` — Синяя, `g` — Мастер игры, `n` — Нейтральная.

3. При успехе сервер начинает слать юниты (те же строки, что и по UDP).
   При ошибке приходит сообщение с префиксом `[LOG]:`, и соединение закрывается.

Сервер фильтрует юниты по коалиции клиента: Красная получает только Red-юниты,
Синяя — Blue, Мастер игры — все.

## Требования

- **Qt 5.15** (модули `core`, `gui`, `widgets`, `network`, `sql`, `positioning`,
  `quickwidgets`; для клиента — также `quick`/QML и `location`)
- Компилятор с поддержкой **C++11** (сервер) и **C++14** (клиент)
  (MSVC 2017+ или MinGW, совместимый со сборкой Qt)
- **SQLite-драйвер** Qt (`QSQLITE`) — входит в стандартную сборку Qt
- Для DCS-скрипта экспорта: библиотека **[LuaSocket](http://w3.impa.br/~diego/software/luasocket/)**
- Для сборки инсталлятора клиента: **Inno Setup 6** (опционально)

## Сборка

Проекты используют **qmake**. Откройте нужный `.pro`-файл в Qt Creator либо соберите из
командной строки, находясь в каталоге соответствующего проекта.

### Сервер

```bash
cd server
qmake dcs-magic-server.pro
mingw32-make          # или nmake / make -j при сборке MSVC
```

### Клиент

```bash
cd client
qmake dcs-magic-client.pro
mingw32-make
```

> При сборке из Qt Creator просто откройте `dcs-magic-server.pro` и `dcs-magic-client.pro`
> и нажмите «Собрать». Убедитесь, что выбран комплект Qt с модулем **Qt Location**.

## Настройка скрипта экспорта в DCS World

1. Скопируйте `lib/lua/MagicExport.lua` в каталог скриптов DCS:

   ```
   %USERPROFILE%\Saved Games\DCS\Scripts\
   ```

   (или `DCS.openbeta\Scripts\` для beta-версии).

2. Убедитесь, что модуль **LuaSocket** распакован рядом со скриптами (в подпапку
   `LuaSocket`), — скрипт подключает его по относительному пути.

3. Убедитесь, что `MagicExport.lua` подключается из основного `Export.lua`:

   ```lua
   userprofile = os.getenv("userprofile"):gsub("\\", "/")
   dofile(userprofile .. "/Saved Games/DCS/Scripts/MagicExport.lua")
   ```

4. При необходимости укажите адрес сервера и порт в начале `MagicExport.lua`
   (по умолчанию — `localhost`, порт `6026`):

   ```lua
   host = "localhost"   -- IP машины, где запущен dcs-magic-server
   port = 6026
   ```

> ⚠️ В мультиплеере DCS данные о юнитах могут быть недоступны или ограничены настройками
> сервера/миссии (`allow_ownship_export` и права экспорта).

## Запуск и конфигурация

### Сервер

1. Запустите `dcs-magic-server`. При первом старте рядом с бинарником создаётся
   `settings.db` (копируется из встроенных ресурсов).
2. Окно показывает **логи** подключений/отключений и **пароли коалиций**.
3. Сервер автоматически слушает:
   - **UDP `0.0.0.0:6026`** — приём данных из DCS;
   - **TCP `0.0.0.0:9085`** — подключение клиентов.

Пароли хранятся в таблице `Access(Coalition, Password)` базы `settings.db`.
Коалиции: `0` — Мастер игры, `1` — Красная, `2` — Синяя.

### Клиент

1. Запустите `dcs-magic-client`.
2. На стартовом экране — кнопки **«Подключиться»** и **«Загрузить запись»**.
3. В диалоге подключения укажите адрес сервера в формате `host:port`
   (по умолчанию `127.0.0.1:9085`), пароль и коалицию.
4. После подключения открывается карта с юнитами; наведите курсор на юнит, чтобы увидеть
   подписи имени и высоты.
5. Меню **«Подключение → Хранилище записей»** и **«Настройки карты → Ночной режим»**
   управляют треками и типом подложки карты.

## Треки (записи)

- Сервер при старте приёма создаёт запись в
  `%USERPROFILE%\Documents\dcs-magic\records\<дата>.txt` и пишет туда весь входящий поток.
- Клиент: **«Загрузить запись»** — выберите `.txt`-файл. Воспроизведение управляется
  горизонтальным **слайдером** внизу окна (перемещение по событиям трека).
- Формат записи — те же строки протокола, разделённые переводом строки.

## Заметки и ограничения

- Порты (`6026` UDP, `9085` TCP) и пароль по умолчанию (`1234`) заданы в коде
  (`udpreceiver.h`, `connectionmanager.cpp`, `connectiondialog.cpp`) и могут быть
  изменены при развитии проекта.
- Авторизация передаётся по TCP **в открытом виде** — используйте доверенную сеть/VPN.
- Экспорт из DCS World передаёт координаты приблизительно (мир DCS — «плоский»),
  поэтому возможны отклонения у границ карт.
- Проект в стадии развития (см. историю коммитов); часть UI-элементов клиента
  (панель выбранного юнита, список юнитов) подключена не полностью.
